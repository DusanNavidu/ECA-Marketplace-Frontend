## Project Description
The frontend application provides the user interface for the ECA Marketplace. It consumes the backend microservices through the Spring Cloud API Gateway deployed on Google Cloud Platform. It supports role-based access for Buyers, Sellers, and Admins, handling product browsing, order placements, and user management.

## Technology Stack
* React.js / Vite
* Tailwind CSS (Styling)
* Axios (API Client)
* Hosted on: Vercel (PaaS / Serverless)
